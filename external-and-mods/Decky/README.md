# Decky plugins (SM8550)

These plugins are carried over from
**[SteamOS-Ubuntu](https://github.com/MaSieS4Fun/SteamOS-Ubuntu)**.

| Plugin | Id | Role |
|--------|----|------|
| [`sm8550/power-managment`](sm8550/power-managment/) | `SM8550-Power` | Energy / power profiles, fan, thermals |
| [`sm8550/color-leds`](sm8550/color-leds/) | `SM8550-LED` | Controller RGB LED panel |
